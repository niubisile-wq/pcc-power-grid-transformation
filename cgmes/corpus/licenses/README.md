# CGMES corpus licence records

This directory records licence evidence for the public packages listed in
`../official_cgmes_corpus_manifest.json`. The manifest is authoritative for
each package's source URL, evidence URL, licence status and redistribution
policy.

Files marked as not redistributable must not be included in a release archive.
ENTSO-E packages identified as CC BY-SA 4.0 require ENTSO-E attribution and
share-alike handling. Packages without verified applicable terms remain local
acquisition artifacts and are represented in public releases by metadata and
SHA-256 hashes only.
